## Призначення та навігація

Цей пакет містить інженерні документи стендового експерименту (Hardware-in-the-Loop, HIL) у межах дослідницького проєкту [fpga-gpu-symbiosis](../../README.md). Експеримент верифікує можливість динамічного оновлення бази знань (правил переходів, компараторів та векторів підписників) у дзеркалі активної пам'яті Block RAM (BRAM) без пересинтезу бітстріму ПЛІС та без переривання наносекундного циклу реакції контуру безпеки ($T_{\text{cycle}} = 80\text{ нс}$).

## Огляд експерименту та науково-патентне значення

1. **Технічна задача:** Доведення спроможності системи до онлайнового навчання (In-Memory Rule Injection & Expertise Escalation) без перезавантаження кристала ПЛІС.
2. **Апаратний механізм:** Використання незалежного Port B двопортової Block RAM у ядрі `CFG-P` для модифікації масок предикатів та таблиць переходів, доки Port A продовжує безперервне виконання реактивного конвеєра з нульовим джитером.
3. **Фіксація результату:** Вимірювання логічним аналізатором Raspberry Pi Pico (RP2040 PIO) відсутності фазових затримок на конвеєрі під час запису в Port B та миттєвої зміни реакції на наступному такті.

## Абревіатури та глосарій

* **BRAM** (Block RAM) — внутрішньокристальна двопортова статична пам'ять ПЛІС.
* **CII** (Computer-Implemented Invention) — комп'ютерно-реалізований винахід.
* **HIL** (Hardware-in-the-Loop) — апаратне тестування в замкненому контурі.
* **Zero-Downtime Rule Injection** — інжекція правил без зупинки роботи контуру безпеки.

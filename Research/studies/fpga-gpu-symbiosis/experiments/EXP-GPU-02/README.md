# Пакет апаратного HIL-експерименту EXP-GPU-02: Динамічне оновлення правил у BRAM (Zero-Downtime Rule Injection)

* **Версія:** 0.2.0
* **Дата:** 2026-11-14
* **Тип WP:** Guide
* **Статус:** Заплановано (Planned; потребує двобанкової гілки `CFG-P-HA` за `B4 Варіант 2`).
* **Власник:** Микола Федчик; автор експерименту — Микола Федчик.

## Призначення та навігація

Цей пакет містить інженерні документи стендового експерименту (Hardware-in-the-Loop, HIL) у межах дослідницького проєкту [fpga-gpu-symbiosis](../../README.md). Експеримент верифікує двобанковий варіант ядра `CFG-P-HA` ([B4 Варіант 2](../../../../../Engineering/specifications/hw/kpol-image-loader-pipeline-contract.md)) для онлайнового оновлення 128-бітних дескрипторів правил у тіньовому банку Block RAM із атомарним перемиканням активного банку між подіями без пересинтезу бітстріму ПЛІС, без `torn-read` та без додаткових тактів затримки основного 8-тактового секвенсера (`80 нс` @ 100 МГц).

## Огляд експерименту та науково-патентне значення

1. **Технічна задача:** Доведення спроможності системи до онлайнового навчання (In-Memory Rule Injection & Expertise Escalation) без перезавантаження кристала ПЛІС.
2. **Апаратний механізм (`CFG-P-HA`, `B4 Варіант 2`):** Оскільки в базовому `CFG-P` (`B4 Варіант 1`) другий порт BRAM зайнятий 8-тактовим секвенсером і одночасний 4-слівний запис призвів би до `torn-read`, для `Zero-Downtime Rule Injection` використовується тіньовий банк Block RAM із атомарним перемиканням активного банку на межі завершення циклу події.
3. **Фіксація результату:** Підтвердження `0 додаткових тактів clk` внутрішнім лічильником ПЛІС та відхилення $|\Delta T_{\text{pipeline}}| \le 1\text{ LSB}$ зовнішнім логічним аналізатором Raspberry Pi Pico (`RP2040 PIO`).

## Абревіатури та глосарій

* **BRAM** (Block RAM) — внутрішньокристальна двопортова статична пам'ять ПЛІС.
* **CII** (Computer-Implemented Invention) — комп'ютерно-реалізований винахід.
* **HIL** (Hardware-in-the-Loop) — апаратне тестування в замкненому контурі.
* **Zero-Downtime Rule Injection** — інжекція правил без зупинки роботи контуру безпеки.

## Призначення та навігація

Цей пакет містить інженерні документи стендового експерименту (Hardware-in-the-Loop, HIL) у межах дослідницького проєкту [fpga-gpu-symbiosis](../../README.md). Експеримент реалізує фізичне стикування плати ПЛІС PYNQ-Z1 (Машина Кузьміна) та обчислювального модуля NVIDIA Jetson AGX Orin 64GB (Seeed Studio reServer Industrial J501) через високошвидкісну шину зв'язку з апаратним моніторингом через логічний аналізатор Raspberry Pi Pico (RP2040) та цифровий осцилограф Raspberry Pi Pico.

## Огляд чотирьох фаз експерименту

1. **Фаза 1 (Baseline SPI DMA):** Базовий трансфер 64-бітної бітової маски подій на частоті SPI 50 МГц.
2. **Фаза 2 (Parallel Bus):** 8-бітний джерельно-синхронний паралельний інтерфейс зі стробом синхронізації ($T_{\text{bus}} \le 160\text{ нс}$).
3. **Фаза 3 (Persistent Mega-Kernel):** Безперервний poll-loop у швидкій пам'яті GPU (Shared Memory / L2 Cache) без участі хост-драйвера.
4. **Фаза 4 (Pico / Raspberry Pi Pico Profiling):** Апаратна фіксація різниці фаз між імпульсом події ПЛІС та стробом реакції GPU ($T_{\text{e2e}} \le 1.0\ \mu\text{с}$, $\sigma \le 50\text{ нс}$).

## Абревіатури та глосарій

* **ADR** (Architecture Decision Record) — запис архітектурного рішення.
* **DMA** (Direct Memory Access) — прямий доступ до пам'яті без участі процесора.
* **HIL** (Hardware-in-the-Loop) — апаратне тестування в замкненому контурі.
* **SPI** (Serial Peripheral Interface) — послідовний синхронний інтерфейс.

# Протокол: Експеримент EXP-GPU-01 — верифікація гетерогенного симбіозу PYNQ-Z1 та Jetson J501 через PicoScope

* **Версія:** 0.1.0
* **Дата:** 2026-11-12
* **Тип WP:** Protocol
* **Статус:** Запропоновано (Proposed).
* **Власник:** Микола Федчик; автор експерименту — Микола Федчик.
* **Підстава:** Архітектурне рішення [B6](../../../../../Engineering/decisions/b6-gpu-persistent-kernel-subscribers.md), загальний протокол дослідження [fpga-gpu-symbiosis](../../protocol.md).

## Питання і межі

### Мета перевірки
Метою експерименту EXP-GPU-01 є фізичне вимірювання наскрізної часової латентності ($T_{\text{e2e}}$) та джитеру ($\sigma$) при передачі зведеного регістра подій із ПЛІС PYNQ-Z1 у персистентний кернел GPU на платформі Seeed Studio reServer Industrial J501 (NVIDIA Jetson AGX Orin 64GB) із реєстрацією часових параметрів цифровим аналізатором/осцилографом Pico (PicoScope).

### Гіпотеза експерименту
1. Використання персистентного CUDA-варпа (Persistent Mega-Kernel) у швидкій пам'яті GPU (SRAM / Shared Memory) усуває софтверний оверхед запуску кернелів (`cudaLaunchKernel`), знижуючи час пробудження обробника події до $T_{\text{wakeup}} \le 150\text{ нс}$.
2. Передача 64/128-бітного зведеного вектора подій через швидкісну шину між PYNQ-Z1 та Jetson J501 забезпечує повний наскрізний цикл виконання 32 нано-колбеків у межах $T_{\text{e2e}} \lt 1.0\ \mu\text{с}$ (проти $100\dots 1000\ \mu\text{с}$ на класичних шинах UART/CAN із фізичними MCU).

### Межі експерименту
* **Охоплює:** Вимірювання фізичних інтервалів між стробом емісії події на ПЛІС (`EVENT_START`) та стробом завершення варпа на GPU (`GPU_DONE`) через прямі провідники роз'ємів GPIO; зняття осцилограм, аналіз джитеру та виявлення Warp Divergence.
* **Не охоплює:** Повну сертифікацію ASIL-D, протокол безпеки для серійних автомобілів та заміну TRL цілої системи.

## Умови та порядок

### Апаратне забезпечення стенда
1. **Генератор подій:** Плата PYNQ-Z1 (Xilinx Zynq-7000 XC7Z020, ядро CFG-P @ 100 МГц).
2. **Обчислювач підписників:** Seeed Studio reServer Industrial J501 (Jetson AGX Orin 64GB, Ampere GPU 2048 ядер).
3. **Вимірювач:** Осцилограф / логічний аналізатор Pico (PicoScope MSO / RP2040 Pico Capture 125 МГц).
4. **Комутація:** Джгут провідників (DuPont / 40-pin ribbon) між 28-піновим роз'ємом Raspberry Pi плати PYNQ-Z1 та 40-піновим GPIO Jetson J501 (3.3V LVCMOS).

### Схема підключення вимірювальних каналів PicoScope
* **Канал CH A (Analog 10x):** Пін FPGA `EVENT_START` (момент фіксації концепту у точці Великої Крапки `•`).
* **Канал CH B (Analog 10x):** Пін Jetson J501 `GPU_DONE` (строб завершення обробки підписників у варпі).
* **Цифрові лінії MSO D0..D7:** Лінії шини передачі даних `D[7:0]` між PYNQ-Z1 та Jetson.

### Порядок виконання вимірювань
1. **Фаза 1 (Базовий SPI DMA контур):**
   * Налаштування PYNQ-Z1 як SPI Slave (50 МГц).
   * Налаштування Jetson J501 як SPI Master з DMA у спільну пам'ять Unified Memory (LPDDR5).
   * Серія з 1000 пакетів емісії події. Вимірювання затримки $T_{\text{e2e}}$.
2. **Фаза 2 (Синхронна паралельна шина GPIO):**
   * Переведення ліній у режим 8-бітної паралельної шини з тактуванням 50 МГц від ПЛІС.
   * Вимірювання часу передачі 128-бітного слова за 16 тактів шини.
3. **Фаза 3 (Латентність персистентного варпа):**
   * Запуск на GPU Jetson Orin персистентного CUDA-варпа з опитуванням кеш-лінії через `__ld_acquire`.
   * Фіксація часу від зміни сигналу на шині до першої інструкції колбека ($T_{\text{wakeup}}$).
4. **Фаза 4 (Стрес-тест на розходження гілок):**
   * Емісія подій із різною кількістю активних бітів підписок ($k = 1, 8, 16, 32$).
   * Зняття гістограми джитеру $\sigma$ в режимі Digital Persistence (100 000 циклів).

## Критерії та дані

| Параметр | Критерій успіху (Acceptance Threshold) | Метод перевірки |
| :--- | :--- | :--- |
| **Латентність трансферу SPI** | $T_{\text{spi}} \le 3.0\ \mu\text{с}$ | Курсорні вимірювання PicoScope |
| **Латентність паралельної шини** | $T_{\text{par}} \le 600\text{ нс}$ | Курсорні вимірювання PicoScope |
| **Пробудження персистентного кернела** | $T_{\text{wakeup}} \le 150\text{ нс}$ | Дельта фронтів CH A та CH B |
| **Наскрізний час ($T_{\text{e2e}}$)** | $T_{\text{e2e}} \lt 1.0\ \mu\text{с}$ (для паралельної шини) | Автоматичні вимірювання PicoScope |
| **Джитер контуру ПЛІС** | $\sigma_{\text{fpga}} = 0\text{ нс}$ (в межах дискретизації) | Гістограма Digital Persistence |
| **Збереження даних** | Сирі осцилограми (`.psdata` / `.csv` / `.vcd`) зберігаються в папці `../../data/` дослідження | Хеш SHA-256 у фінальному звіті |

## Абревіатури та глосарій

* **DMA** — Direct Memory Access (прямий доступ до пам'яті).
* **MSO** — Mixed Signal Oscilloscope (осцилограф змішаних сигналів).
* **Persistent Kernel** — довготривалий процес GPU у Shared Memory.
* **VCD** — Value Change Dump (формат запису цифрових часових діаграм).
* **WCET** — Worst-Case Execution Time (найгірший час виконання).

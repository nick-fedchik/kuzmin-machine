# План: Проведення експерименту EXP-GPU-01 на стенді PYNQ-Z1, Jetson J501 та Raspberry Pi Pico

* **Версія:** 0.2.0
* **Дата:** 2026-11-14
* **Тип WP:** Plan
* **Власник:** Микола Федчик; автор експерименту — Микола Федчик.
* **Підстава:** Протокол [EXP-GPU-01](protocol.md), архітектурне рішення [B6](../../../../../Engineering/decisions/b6-gpu-persistent-kernel-subscribers.md), загальний план дослідження [fpga-gpu-symbiosis](../../README.md).

## Мета і межі

### Призначення плану
Цей план визначає графік робіт, передумови, підготовку апаратури та порядок зняття фізичних результатів експерименту EXP-GPU-01. Метою є отримання верифікованих цифрових часових рядів, що перевіряють спроможність зв'язки ПЛІС із персистентним кернелом GPU виконувати 32 нано-підписки з наскрізною латентністю $T_{\text{e2e}} \lt 1.0\ \mu\text{с}$.

### Межі робіт
* **Входить у план:** Розробка експериментального RTL-модуля `PMOD Event Egress` для PYNQ-Z1 (`SPI` / 8-бітна паралельна шина на `PMOD JA/JB`), розробка CUDA-коду персистентного кернела для Jetson AGX Orin, фізичний монтаж узгодженого за рівнями (`3.3V <-> 1.8V/3.3V`) з'єднувача, конфігурація цифрового логічного аналізатора `RP2040 PIO`, проведення випробувань та укладання фінального звіту `report.md`.
* **Не входить у план:** Розробка серійних багатошарових друкованих плат (PCB) або зміна внутрішньої транзакційної логіки незмінного шлюзу ядра `CFG-P`.

## Кроки й залежності

### Етап 1: Підготовка програмного та апаратного забезпечення
1. Складання тестового проекту для PYNQ-Z1 у тулчейні OpenXC7 / Vivado:
   * Інтеграція модуля зведення бітової маски концептів у вихідний регістр шини;
   * Виведення стробу `EVENT_START` на тестовий пін PMOD JA1;
   * Реалізація SPI Slave (50 МГц) та опційного 8-бітного паралельного трансівера.
2. Підготовка хост-оточення на Seeed Studio J501 (NVIDIA Jetson AGX Orin):
   * Написання мінімального CUDA-файлу `persistent_subscribers.cu`;
   * Реалізація фонового варпа з циклом `__ld_acquire` та буфером Shared Memory;
   * Налаштування драйвера SPI DMA або швидкісного доступу до GPIO (`/dev/spidev` / mmap GPIO).

### Етап 2: Фізичний монтаж та перевірка цілісності сигналів
*(Детальний аналіз електричної схеми та розпіновки див. у [j501-hardware-interface.md](j501-hardware-interface.md))*
1. Комутація вимірювального контуру:
   * **Промисловий рівень (12V/24V / CAN-FD):** Підключення через 20-контактний клемник `J25` (ізольовані оптрони SFH690BT, трансивери TPT71044). Затримка $\tau \approx 5\dots 15\ \mu\text{с}$ (підходить для PLC та телеметрії, але перевищує бюджет $T_{\text{e2e}} \le 1.0\ \mu\text{с}$).
   * **Високошвидкісний наносекундний тракт (EXP-GPU-01):** Для тестування $T_{\text{wakeup}} \le 150\text{ нс}$ підключення PYNQ-Z1 $\to$ Jetson виконується через швидкісні цифрові канали без оптоізоляції (лінії PMOD / High-Speed Header / Ethernet UDP Raw) або через внутрішнє апаратне профілювання CUDA `clock64()`.
   * Перевірка надійності спільних провідників заземлення (GND) для запобігання фазовому дзвону (Ringing).
2. Підключення цифрових входів логічного аналізатора `RP2040 PIO` (`3.3V LVCMOS`):
   * `GP0` $\to$ пін `EVENT_START` на PYNQ-Z1;
   * `GP1` $\to$ буферизований до `3.3V` пін `GPU_DONE` на виході контуру;
   * `GP2..GP9` $\to$ цифрові лінії шини даних і синхронізації (перевірка аналогових фронтів на `50 МГц` виконується окремим зовнішнім осцилографом $\ge 200\text{ МГц}$, а не АЦП RP2040).

### Етап 3: Проведення прогонів та збір сирих даних
1. Прогін серії 1: Вимірювання SPI DMA контуру ($N = 1000$ імпульсів).
2. Прогін серії 2: Вимірювання синхронної паралельної шини ($N = 1000$ імпульсів).
3. Прогін серії 3: Статистичне накопичення джитеру ($N = 100\,000$ імпульсів цифрового захвату + `clock64()`).
4. Експорт первинних цифрових трас (`.vcd` / `.csv`) у `../../data/` із фіксацією SHA-256.

## Абревіатури та глосарій

* **CFG-P** — конфігурація конвеєра Машини Кузьміна на Block RAM.
* **HIL** — Hardware-in-the-Loop.
* **Persistent Kernel** — персистентне ядро GPU.
* **RP2040 PIO** — програмований блок цифрового вводу-виводу Raspberry Pi Pico (логічний аналізатор із кроком `8 нс` @ 125 МГц).
* **Unified Memory** — спільна пам'ять LPDDR5 процесора та GPU на Jetson Orin.

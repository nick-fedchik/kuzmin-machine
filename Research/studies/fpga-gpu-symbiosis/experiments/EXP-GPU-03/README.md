# Пакет експерименту EXP-GPU-03: Гетерогенні підписники у варпі GPU, спеціалізація варпів, профіль MAXN та ізоляція TSG

* **Дата:** 2026-11-16
* **Тип WP редакції NG:** Guide
* **Статус:** Виконано на фізичному стенді NVIDIA Jetson AGX Orin ([#256](https://github.com/nick-fedchik/kuzmin-machine/issues/256)); очікує незалежної рецензії.

## Призначення та навігація

Цей пакет містить вихідний код CUDA-кернела, агрегатор повторюваності та звіт експерименту `EXP-GPU-03` ([#256](https://github.com/nick-fedchik/kuzmin-machine/issues/256)) у межах дослідницького напряму [fpga-gpu-symbiosis](../../README.md). Експеримент розширює однорідну базу [EXP-GPU-01](../EXP-GPU-01/report-phase3-warp-scaling.md) на чотири змістовно різні класи stateful-операторів підписників у регістрах SM (`16 SM x 64 нитки = 1024` підписники), кількісно вимірює штраф внутрішньоварпової серіалізації `mixed_warp` проти спеціалізації варпів `grouped_warp`, а також перевіряє вплив частотного профілю `MAXN` (`1300.5 МГц`) і закріплення хост-нитки `--rt-pin` (`CPU 11 + SCHED_FIFO` пріоритету `80`) на хвостовий квантиль `p99.9(T_e2e_sm)` та сплески витіснення `nvgpu` TSG.

## Ключові параметри експериментальної матриці `S1..S5`

Усі 5 серій виконано за геометрії `16 SM x 64 нитки = 1024` підписники з розкладкою `ingress_mode=partitioned`, `ack_mode=isolated`, `mask=rand` по $R = 5$ незалежних процесів $\times$ $N = 10\,000$ подій (`250 000` пакетів подій сумарно):

1. **`S1` (`MODE_50W`, `816.0 МГц`):** `layout=homo_pid` (`1024` ПІД з anti-windup), звичайний планувальник `SCHED_OTHER` — однорідна контрольна база.
2. **`S2` (`MODE_50W`, `816.0 МГц`):** `layout=mixed_warp` (`op_type = lane_id & 3`, усі 4 оператори активні в кожному варпі) — прямий вимір ціни внутрішньоварпової серіалізації.
3. **`S3` (`MODE_50W`, `816.0 МГц`):** `layout=grouped_warp` (`op_type = warp_global & 3`, спеціалізація варпів за класом оператора) — перевірка усунення штрафу дивергенції на тому самому наборі з `4 x 256` підписників.
4. **`S4` (`MAXN`, `1300.5 МГц`):** `layout=grouped_warp`, звичайний планувальник — перевірка масштабування за частотою та досяжності порога `p99.9(T_e2e_sm) <= 1500 нс`.
5. **`S5` (`MAXN`, `1300.5 МГц`):** `layout=grouped_warp`, `--rt-pin` (`CPU 11 + SCHED_FIFO:80`) — перевірка впливу ізоляції публікатора ARM на `Host RT` і сплески `nvgpu` TSG.

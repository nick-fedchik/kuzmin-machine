# Дослідницький пакет: Гетерогенний симбіоз Машини Кузьміна та GPU (FPGA-GPU Symbiosis)

* **Версія:** 0.2.0
* **Дата:** 2026-11-13
* **Тип WP:** Guide
* **Статус:** Дослідження відкрито (Active Research).
* **Власник:** Микола Федчик; автор дослідницької гіпотези — Микола Федчик.

## Призначення та склад пакета

Дослідження присвячене розв'язанню проблеми затримки виконання підписок на події (Callback Bottleneck) у розподілених подієвих системах та Машині Кузьміна (МК). Метою є перевірка концепції гетерогенного об'єднання швидкісного апаратного ядра ПЛІС із масивно-паралельним графічним процесором (GPU), де банк підписників утримується в надшвидкій пам'яті (SRAM / Shared Memory / L2 Cache) GPU у вигляді персистентного ядра (Persistent Mega-Kernel) на базі універсальних шейдерних ядер (CUDA Cores / Stream Processors / Xe Vector Engines).

## Абревіатури та глосарій

* **ADR** (Architecture Decision Record) — запис архітектурного рішення.
* **CME** (Cellular Micro-Engine) — клітинний мікро-рушій обробки подій МК.
* **GPU** (Graphics Processing Unit) — графічний процесор масивно-паралельних обчислень.
* **HIL** (Hardware-in-the-Loop) — апаратне тестування в замкненому контурі.
* **MMIO** (Memory-Mapped I/O) — введення-виведення з відображенням у пам'ять.
* **ПЛІС** (FPGA) — програмована логічна інтегральна схема.

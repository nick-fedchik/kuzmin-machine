* **Версія:** 0.1.0
* **Дата:** 2026-11-12
* **Тип WP:** Guide
* **Статус:** Очікування фізичних вимірювань стенду (Awaiting Data).
* **Власник:** Микола Федчик.

## Призначення каталогу

Цей каталог призначений для збереження первинних експериментальних даних (Data), отриманих під час виконання експерименту [EXP-GPU-01](../experiments/EXP-GPU-01/README.md):
1. **Файли цифрових трас (`.vcd`):** записи логічного аналізатора Raspberry Pi Pico (RP2040) на частоті дискретизації 125 МГц (часовий крок 8 нс).
2. **Осцилограми (`.csv`, `.png`):** аналогові та змішані осцилограми PicoScope MSO, що фіксують різницю фаз між імпульсом детекції події на ПЛІС (CH_A) та імпульсом підтвердження виконання в GPU (CH_B).
3. **Журнали затримок (`.json`, `.csv`):** статистичні вибірки тривалості $T_{\text{e2e}}$ для серій із 1000 імпульсів при різній частоті вхідного потоку.

## Правила збереження первинних записів

* Первинні файли вимірювань є незмінними вхідними даними (immutable raw data).
* Будь-яка аналітична обробка (розрахунок середнього $\mu$, джитера $\sigma$, побудова гістограм) виконується окремими скриптами без перезапису оригінальних записів.

## Абревіатури та глосарій

* **CSV** (Comma-Separated Values) — текстовий формат табличних даних.
* **MSO** (Mixed-Signal Oscilloscope) — осцилограф змішаних сигналів.
* **VCD** (Value Change Dump) — стандартний формат часових діаграм цифрових сигналів.

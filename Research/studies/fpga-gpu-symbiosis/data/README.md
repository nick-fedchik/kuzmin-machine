* **Версія:** 0.2.0
* **Дата:** 2026-11-14
* **Тип WP:** Guide
* **Статус:** Очікування фізичних вимірювань стенду (Awaiting Data).
* **Власник:** Микола Федчик.

## Призначення каталогу

Цей каталог призначений для збереження первинних експериментальних даних (Data), отриманих під час виконання експериментів [EXP-GPU-01](../experiments/EXP-GPU-01/README.md) та [EXP-GPU-02](../experiments/EXP-GPU-02/README.md):
1. **Файли цифрових трас (`.vcd`, `.sr`):** записи цифрового логічного аналізатора Raspberry Pi Pico (`RP2040 PIO`, `3.3V LVCMOS`) на частоті дискретизації `125 МГц` (крок `8 нс`) або `250 МГц` (крок `4 нс`).
2. **Опційні осцилограми аналогової цілісності сигналів (`.csv`, `.png`):** траси зовнішнього цифрового осцилографа зі смугою $\ge 200\text{ МГц}$ (якщо залучений на етапі контролю фронтів та перехідних процесів між PYNQ-Z1 і Jetson J501; вбудований SAR ADC RP2040 на `500 kSPS` для наносекундних аналогових вимірювань не використовується).
3. **Журнали затримок (`.json`, `.csv`):** статистичні вибірки тривалості $T_{\text{e2e}}$ та показників внутрішніх апаратних лічильників ПЛІС і `clock64()` GPU для серій із 1000+ імпульсів.

## Правила збереження первинних записів

* Первинні файли вимірювань є незмінними вхідними даними (immutable raw data).
* Будь-яка аналітична обробка (розрахунок середнього $\mu$, джитера $\sigma$, побудова гістограм) виконується окремими скриптами без перезапису оригінальних записів.

## Абревіатури та глосарій

* **CSV** (Comma-Separated Values) — текстовий формат табличних даних.
* **RP2040 PIO** — програмований автомат цифрового вводу-виводу Raspberry Pi Pico.
* **VCD** (Value Change Dump) — стандартний формат часових діаграм цифрових сигналів.

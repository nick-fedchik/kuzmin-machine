# Дослідження

* **Версія:** 0.1.0
* **Дата:** 2026-11-12
* **Тип WP:** Guide
* **Супровід:** власник проєкту; оновлення за результатом дослідження.

## Призначення

Навігація за питаннями, не за розширеннями файлів. Пакет може містити
Problem, Model, Protocol, Report і Data як документи, розділи або зв'язки.
Тип WP не вимагає створення окремого файла.

## Обмеження

Стан узято зі збережених звітів на джерельному SHA, а не з нового
зовнішнього пошуку. Закриття старої Issue не закриває наукове питання.
Історичні досьє, старі пропозиції мови й архіви сюди не перенесено;
доступ до них за потреби — через точні посилання походження.

## 1. Що не вдалося і обмеження

1. **Історичні raw-логи не виправлено.** `raw/open-flow-01.log` (#151) та всі логи в `axi-b4-pynq-168/raw/` містять лише `=== Code commit SHA ===`, без точного виклику команди (з параметрами) і ISO 8601 timestamp запуску. Згідно з AGENTS.md §4.5 («сирі дані незмінні») ці файли не редагувалися заднім числом — відсутність точного provenance для вже зафіксованих прогонів лишається задокументованим обмеженням, а не виправляється підробкою historical даних.
2. **`check_report_provenance.py` не застосовується до `Engineering/validation/kpol-cme/`.** Контракт `report-provenance.md` охоплює лише `Engineering/validation/experiments/`; звіти #151/#168 поза цією областю, тому структурний інструмент не перевіряє їхнє трасування автоматично. Розширення області контракту — окрема задача, не вирішена цим Report.
3. **Виправлення — суто формулювання та документація**, без повторного запуску EDA-потоку чи апаратних тестів: нові числа не заявлено, лише уточнено інтерпретацію вже зафіксованих (#151) та додано конвенцію на майбутнє (шаблон звіту).

## 2. Метод

1. Перевірено сигнал маскування `hw_trigger_ready_o` у `kpol_bram_pipeline_axi.sv:94`: `wire ext_trigger_blocked = sw_trigger || bram_we || cfg_write_fire;` — підтверджено прямим переглядом RTL та тестом `test_kpol_bram_pipeline.py:717-718`.
2. Перевірено, що `sampled_state_q` (`km_concept_micro_engine.sv:138-151`) — скалярний регістр без підтримки конкурентного стану кількох концептів в одному екземплярі CME; інваріант раніше не був задокументований прямо в коді.
3. Переглянуто оригінальний текст знахідок F1 (PR #163 Review Report щодо формулювання lint) та F1 (PR #174 Review Report щодо відсутності command/timestamp у raw-логах) через `gh pr view --json comments`.
4. Звірено вміст `raw/open-flow-01.log` (#151) та всіх файлів `axi-b4-pynq-168/raw/*.log` (#168) на наявність заголовків command/timestamp — підтверджено відсутність в обох випадках (лише SHA коміту).
5. Інструментальні перевірки: `python3 -m pytest -q`, `python3 Project/tools/check_links.py`, `python3 Project/tools/check_wp_documents.py`.

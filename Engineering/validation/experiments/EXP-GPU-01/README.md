## Призначення та навігація

Цей пакет містить повний набір інженерної документації та конфігурацій для проведення натурного апаратного експерименту зі стикування ПЛІС PYNQ-Z1 (Машина Кузьміна) та платформи NVIDIA Jetson AGX Orin 64GB (Seeed Studio reServer Industrial J501) через високошвидкісну шину та апаратний моніторинг за допомогою логічного аналізатора Raspberry Pi Pico (RP2040) / PicoScope.

## Огляд експерименту

Експеримент спрямований на практичну перевірку та вимірювання затримок усунення Callback Bottleneck шляхом перенесення банку нано-підписників подій у швидку статичну/спільну пам'ять (SRAM / Shared Memory / L2 Cache) GPU Jetson Orin:
1. **Фаза 1 (Baseline SPI DMA):** Базове опитування та SPI DMA трансфер бітової маски подій на частоті 50 МГц.
2. **Фаза 2 (Parallel Bus):** 8-бітний джерельно-синхронний паралельний інтерфейс зі стробом передачі для мінімізації латентності ($T_{\text{e2e}} \le 1.0\ \mu\text{с}$).
3. **Фаза 3 (Persistent Mega-Kernel):** Постійно активний кернел CUDA з poll-loop за низьколатентним бар'єром пам'яті.
4. **Фаза 4 (Pico Latency Profiling):** Апаратне вимірювання $T_{\text{react}}$ та $T_{\text{e2e}}$ через Pico 125 MHz (8 ns) / PicoScope MSO.

## Абревіатури та глосарій

* **ADR** (Architecture Decision Record) — запис архітектурного рішення.
* **DMA** (Direct Memory Access) — прямий доступ до пам'яті.
* **HIL** (Hardware-in-the-Loop) — апаратне тестування в контурі керування.
* **SPI** (Serial Peripheral Interface) — послідовний синхронний інтерфейс зв'язку.
* **SRAM** (Static Random-Access Memory) — швидка статична пам'ять.

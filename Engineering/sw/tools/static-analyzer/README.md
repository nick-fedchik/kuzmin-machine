# Статичний аналізатор

* **Версія:** 0.1.1
* **Дата:** 2026-11-12

У каталозі зберігаються експериментальний [аналізатор](km_static_analyzer.py),
його [тести](tests/test_km_static_analyzer.py) та перенесений із колишнього
README [математичний і проєктний опис](design-analysis.md).

Опис є похідним матеріалом; його наявність не підтверджує повноти семантики
МК, реалізованості всіх заявлених можливостей чи гарантованого WCET.

Демонстрація і тести з кореня репозиторію:

```bash
python3 Engineering/sw/tools/static-analyzer/km_static_analyzer.py
python3 -m pytest Engineering/sw/tools/static-analyzer/tests
```


* **Тип WP редакції NG:** Guide
* **Укладач редакції NG:** GitHub Copilot CLI, Auto; конкретна модель не атестована.
* **Підстава редакції NG:** команда власника від 2026-11-12; локальне перенесення без legacy.
* **Походження:** [оригінал 0.1.0](https://github.com/nick-fedchik/kuzmin-machine/blob/707fdba697d92ef9874c9013eb6f4f3cb2796d70/sw/tools/static-analyzer/README.md), `707fdba697d92ef9874c9013eb6f4f3cb2796d70`.
* **Стан редакції NG:** адаптовано до нової структури; незалежна рецензія не проведена.

> **Межі редакції NG.** Перенесення й оформлення не є новим експериментом,
> повторною науковою перевіркою або затвердженням baseline. Авторство,
> рішення, числа й рецензії нижче стосуються зазначених оригінальних
> об'єктів та версій, а не автоматично цієї локальної копії.

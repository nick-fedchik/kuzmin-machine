## Подальше використання

[Драйвер](baseline_replay.py) за замовчуванням заново виконує всі AV,
включно з P&R. Для економного режиму додається явний
`--reuse-recorded-pnr`: він перевіряє зафіксовані старі результати,
а не видає їх за нове трасування. Обидва режими порівнюють усі 59 рядків.

Потрібні чистий source-клон на вказаному SHA та нові output/build:

```bash
python3 process/validation/75-reproduce-av/baseline_replay.py \
  --source ../km-repro-75-clean --out /tmp/km75-new-raw --build /tmp/km75-new-build
```

Для #75 нова база замінює вимогу відновлення старих історичних SHA.
Решта критеріїв S1 — реєстр міграції, CI і версійний тег — оцінюється
окремо. Архівний хеш більше не є умовою приймання #75.

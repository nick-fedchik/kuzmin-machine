## 0. Як читати паспорт

Для кожного рівня наведено:
- критерій ISO 16290;
- **первинні** докази — тексти й матеріали автора концепції М. Ю. Кузьміна;
- **похідні** докази — документи, які написав М. Федчик або агенти проєкту;
- обмеження, тобто що рівень **не** доводить;
- стан незалежної перевірки.

Окремої авторської технічної специфікації 2026 року **не існує** (F11 у [реєстрі міграції](../MIGRATION-REGISTER.md)). Те, що раніше так називалося, — реконструкція М. Федчика.

**Критерій ISO 16290:** наукові дослідження починають переходити в прикладні; описано базові властивості.

| Особисте спілкування М. Федчика з автором | Первинний, усний | Не задокументовано. Кожне використане твердження треба записати з датою (Issue) |
| Формальний розбір: події, підписки, симуляція МТ | Похідний (реконструкція М. Федчика) | [docs/theory/formal-analysis.md](../../docs/theory/formal-analysis.md) |

**Обмеження:**
- принципи описано текстом і прикладами автора;
- математичного доведення еквівалентності МТ від автора немає — ескіз конструкції є лише в реконструкції;
- оператор `•` і модель стеків відомі в переказі М. Федчика.

**Незалежна перевірка:** наукова опозиція ([docs/trl-evidence/scientific-opposition-report.md](../../docs/trl-evidence/scientific-opposition-report.md)) — вердикт «суттєво не обґрунтовано» щодо ширших тверджень. Базову модель (концепти, предикати-події, підписки) визнано правдоподібною. Рецензії самого паспорта немає.

**Самооцінка:** TRL 1 досягнуто. Принципи описано в первинних джерелах.

## 3. TRL 3 — аналітичне та експериментальне підтвердження критичної функції (PoC)

**Критерій ISO 16290:** активні дослідження; аналітичні й лабораторні дослідження підтверджують критичну функцію.

**Критична функція PoC:** транзакційний fail-closed шлюз зміни стану концепту за один такт, без лічильника команд.

| Доказ | Що показує | Review Report | Відтворено в цьому репо (2026-11-09) |
| :--- | :--- | :--- | :--- |
| [AV-04](../../experiments/AV-04/report.md) — формальна верифікація `kpol_txn_gate` v1 (k-індукція, Z3 / cvc5) | Fail-closed; commit і reject взаємовиключні; оновлення лише за виконаних передумов | Gemini: «Прийнято із зауваженнями» | Так: `AV-04 OVERALL: PASS` |
| [AV-07](../../experiments/AV-07/report.md) v2.0 — мутаційне тестування тестбенчів | 22 з 22 мутантів убито | v1.0 — «не приймати». Вердикт для v2.0 дописав автор виправлення (F4) | Так: 22/22, ті самі стадії |
| [AV-08](../../experiments/AV-08/report.md) — масштабування на Zynq-7020 | Гіпотезу N = 64 @ 100 МГц спростовано; межа N ≤ 32 | Gemini: «Прийнято» | Аналіз сирих даних збігся побайтно; синтез повторно не запускали |
| [AV-03](../../experiments/AV-03/report.md) — програмне рішення шлюзу на CPU | Порівняльна база: 2,95–47 нс на рішення | Copilot: «прийняти лише після виправлень» | Лише диференційний тест C ↔ Python |
| Тестбенчі [`hw/tb/`](../../hw/tb/) | 10 з 11 проходять; `axi_lite_tb` падає (F12) | — | Так, `pytest hw/tests` |
| HIL-скрипти [`hw/boards/pynq-z1/hil/`](../../hw/boards/pynq-z1/hil/) | Робота на PYNQ-Z1 | Звіти QA PoC без рецензії (F7) | Ні |

**Обмеження:**
- доведено для ядра `kpol_txn_gate` v1; `v2`, мікро-рушій і секвенсер формально не верифіковано;
- демонстраційні FSM (`hw/rtl/poc-demo/`) — жорстко закодовані задачі, а не універсальна машина (прогалина 1);
- логіку предикатів змінити без пересинтезу неможливо (прогалина 2);
- ядро кероване з PS через AXI; 84 мкс H4 — це затримка Python + `pynq.MMIO`, а не шини (F10, прогалина 3);
- наскрізного ланцюжка KPOL → бітстрім немає (прогалина 4);
- AXI-тестбенч падає (F12).

**Самооцінка:** TRL 3 досягнуто для критичної функції шлюзу. Лабораторну валідацію компонента (TRL 4) не досягнуто: див. [маршрут](../PROJECT-MANUAL.md#4-віхи-trl-і-маршрут-до-mvp).

## 5. Що потрібно, щоб віхи TRL 1–3 закрити

1. Review Report на цей паспорт від рецензента, який не є укладачем.
2. Записати використані твердження з особистого спілкування з автором (дата, зміст), або прибрати їх із похідних документів.
3. Незалежна рецензія AV-07 v2.0 (F4).
4. Аудит за [методикою](../audit/ASPICE-Audit-Method.md) з вердиктом щодо TRL 3.

# Шаблони Work Products

* **Версія:** 0.1.0
* **Дата:** 2026-11-12

Обирайте шаблон за призначенням із [конфігурації WP](../../../docs/governance/work-products.md).
Шаблони — допомога, а не вимога створювати окремий документ для кожного WP.
Приберіть непридатні розділи, додайте потрібні й не вигадуйте невідомі дані.

| WP | Шаблон |
|---|---|
| Problem | [Постановка питання](problem.md) |
| Model | [Модель](model.md) |
| Requirement | [Вимога](requirement.md) |
| Specification | [Специфікація](specification.md) |
| Design | [Конструкція](design.md) |
| Decision / ADR | [Рішення](decision.md) |
| Plan | [План](plan.md) |
| Protocol | [Протокол](protocol.md) |
| Report / Analysis | [Аналітичний звіт](analysis-report.md) |
| Report / Experiment | [Звіт про експеримент](../report.md) |
| Report / Review | [Рецензія](../review.md) |
| Guide | [Посібник або README](guide.md) |

Дані, вихідний код, конфігурація та фізичний пристрій не потребують
штучного текстового шаблону. Для походження результатів експериментів
застосовується чинний [контракт](../../../tools/report-provenance.md).

# Специфікації KPOL

* **Версія:** 0.2.0
* **Дата:** 2026-11-12

**Починати розробку компілятора з
[консолідованого робочого контракту](kpol-consolidated-0.1.0.md).**
Він об'єднує синтаксис поточного фронтенду, семантику референсу,
формат виконуваного CME-образу, приклад запуску та матрицю підтримки.
Це чернетка для [#19](https://github.com/nick-fedchik/kuzmin-machine/issues/19)
і [#8](https://github.com/nick-fedchik/kuzmin-machine/issues/8), не
затверджений стандарт v1.0 та не доказ коректності всіх прийнятих програм.

Особливо: `compile_bram_image` і `compile_concept_microcode_bram_image`
створюють різні 1024-байтні формати; їх не можна взаємозамінювати.
Успішний парсинг не означає підтримки відповідної конструкції CME-бекендом.

## Історичні входи

Специфікації v0.2–v0.9 — **дельти** попередніх пропозицій. Нижче
збережено їхній індекс і попередні оцінки для історії; актуальні межі
реалізації наведено в матриці §6 робочого контракту. Стабільні шляхи
не видалено, оскільки вони потрібні посиланням і тестам.

Незалежний аудит v0.2–v0.9: [reviews/kpol-0.2-0.9-audit-review.md](reviews/kpol-0.2-0.9-audit-review.md) — вердикт **No-Go для стандарту v1.0**. Виправлення за аудитом: [experiments/KPOL-FIX/report.md](../../experiments/KPOL-FIX/report.md).

без аудиту відповідності; вона не замінює нову матрицю підтримки.
Незалежна рецензія консолідації та рішення про цільову підмножину ще потрібні.

Версії файлів — SemVer 2: `0.N.0` відповідає колишній `vN.0`. Файл `kpol-0.1.0.md` — колишня «Draft».

# Демонстраційні FSM доказу концепції (PoC)

* **Версія:** 0.1.0
* **Статус:** **застаріле, підлягає вилученню на кроці S3** (незмінне ядро).

Модулі цього каталогу — жорстко закодовані під конкретні задачі кінцеві автомати. Вони показують окремі патерни, але не доводять існування універсальної машини (прогалина 1 у [плані рефакторингу](../../../architecture/refactoring-plan.md)).

| Модуль | Патерн | Хто використовує |
| :--- | :--- | :--- |
| `km_euclid_core.sv` | Алгоритм Евкліда на подіях | AXI-обгортка, AV-07 |
| `km_rcfc_engine.sv` | Рандеву між стеками (RCFC), TC-01…TC-04 | AXI-обгортка, AV-07, AV-08 |
| `km_cascade_arbiter_engine.sv` | Каскад і арбітр, TC-05…TC-08 | AXI-обгортка, AV-07 |
| `km_stream_pipeline_engine.sv` | Потоковий конвеєр | AXI-обгортка, AV-07 |

Чому вони тут, а не в архіві: їх інстанціює [`kpol_txn_gate_axi_lite.sv`](../bus/kpol_txn_gate_axi_lite.sv). Без них не збираються бітстрім PYNQ-Z1 і не відтворюються AV-07 і AV-08. Нові функції на них **не будувати**.

Відомі попередження Verilator `-Wall` у цих модулях (невикористані параметри й сигнали, розширення розрядності) — F13 у [реєстрі міграції](../../../process/MIGRATION-REGISTER.md). Не виправляються, бо модулі підлягають вилученню.

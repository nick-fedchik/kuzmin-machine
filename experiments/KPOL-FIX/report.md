## 1. Реєстр критичних дефектів та цільові критерії виправлення

| ID | Дефект | Першопричина | Критерій справжньої перевірки (Pass Criteria) |
| :--- | :--- | :--- | :--- |
| **F-01** | C-рантайм містить хардкод `param > 100`, не оновлює стан, ігнорує `event_id` | Макет замість AST-кодогенератора | Реальний AST-транслятор виразів у C; компіляція згенерованого C-файлу через `gcc -std=c99 -Wall -Wextra -pedantic` та його успішне виконання в тестовому драйвері з перевіркою паритету з Python-еталоном |
| **F-02** | Інтерпретатор за замовчуванням Fail-Open (`fail_closed_hazards=False`) | Успадкована чернетка v0.1 | `fail_closed_hazards = True` за замовчуванням скрізь; активний Hazard безумовно відхиляє номінальний коміт у Python точно так само, як у Verilog RTL |
| **F-03** | Verilog-інтерконект — пустий пастру (`committed_o = event_strobe_i`) | Імітація обв'язки | Генерація реального апаратного інтерконекту, який інстанціює `kpol_txn_gate_v2` з `FAIL_CLOSED_HAZARDS = 1`, з успішною симуляцією в `iverilog` |
| **F-04** | AXI4-Lite обгортка грубо порушує протокол AMBA | Відсутність FSM рукостискання | Повна реалізація AXI4-Lite Slave FSM з роздільними буферами AW/W, `WSTRB`, `bready/rready` backpressure; симуляція в `iverilog` усіх 4 протокольних кейсів |
| **F-05** | Заява про зміну логіки через 1024b BRAM без пересинтезу не реалізована | Завищені твердження специфікації | Чесне обмеження: компілятор явно відхиляє >16 правил з помилкою `KpolError`, дескриптор документується як таблиця конфігурації станів |
| **F-06** | Secure Boot без захисту від replay, детермінований nonce, малий ключ | Безстанова верифікація | Перевірка мінімальної довжини ключа ($\ge 16$ байтів), валідація прапорців `FLAGS`, збереження та перевірка унікальності nonce (anti-replay) |
| **F-07** | Незалежність тріади фіктивна (склеювання рядків, порожній proof) | Поверхневий парсер | Обов'язкова наявність `.kproof` з хоча б одним тестом; криптографічне хешування SHA-256 складових тріади для аудиту DO-178C |
| **F-08/09** | Попперівський гейт вакуумно проходить при 0 мутантів; мутації неповні | Неповний AST-візитор | Викидання помилки, якщо при наявності правил згенеровано 0 мутантів; мутація складених зв'язок (`and`/`or`); вбудовування виклику гейту в компіляцію |
| **F-10** | Hardware ACL — функція, яку ніхто не викликає | Відсутність прив'язки до пайплайну | Обов'язковий виклик `check_module_security_acl` у `compile_*`. Будь-яке порушення прав доступу до пінів блокує компіляцію з помилкою |

## 2. Протокол виконання робіт

1. **Модуль ядра `kpol_reference.py`:**
   - [x] Зміна дефолту `Interpreter.fail_closed_hazards = True`.
   - [x] Реалізація AST-транслятора виразів `_ast_expr_to_c(expr, state_names, event_params) -> str`.
   - [x] Реалізація повного C-генератора `compile_baremetal_runtime`: генерація структур станів, `switch (event_id)`, умов `Assumptions`, `Hazards`, мутації станів та перевірки `Invariants`.
   - [x] Реалізація стандартизованого модуля `compile_axi_lite_wrapper` з повноцінною машинкою станів AMBA AXI4-Lite (незалежні канали `AW` і `W`, `WSTRB`, `bvalid/bready`, `rvalid/rready`).
   - [x] Реалізація реального `compile_verilog_interconnect` з інстанціацією `kpol_txn_gate_v2`.
   - [x] Впровадження обов'язкової перевірки `check_module_security_acl` перед компіляцією.
   - [x] Розширення генератора мутантів (складені оператори `and/or`, обидві сторони порівняння) та захист від вакуумного проходження ($M = 1.0$ при 0 мутантів $\to$ помилка).
   - [x] Посилення `parse_triad_files`: обов'язковий непорожній `.kproof`, розрахунок SHA-256 хешів компонентів.
   - [x] Посилення `verify_bram_signature`: мінімальний ключ 16 байтів, перевірка `flags`, відхилення повторного nonce.

2. **Модуль тестів `test_kpol_reference.py`:**
   - [x] Тест 1 (Real GCC Compilation): автоматична генерація C-рантайму, запис у тимчасовий каталог, генерація драйвера `main()`, виклик `/usr/bin/gcc -std=c99 -Wall -Wextra -pedantic`, запуск скомпільованого двійкового файлу і перевірка його статусів.
   - [x] Тест 2 (Real Iverilog Simulation): генерація AXI4-Lite slave RTL, генерація Verilog тестбенча з перевіркою всіх 4 кейсів рукостискання (AW перед W, W перед AW, backpressure, wstrb), компіляція через `/usr/bin/iverilog -g2012` та запуск через `/usr/bin/vvp`.
   - [x] Тест 3 (Real Fail-Closed Parity): перевірка, що за замовчуванням `Interpreter(module)` відхиляє транзакцію при активному Hazard (паритет із вентилем v2).
   - [x] Тест 4 (Anti-Replay & Anti-Vacuum): тести відхилення коротких ключів, повторних nonce та вакуумних модулів без мутантів.
   - [x] Тест 5 (Real Python ↔ C Parity): передача однакових послідовностей подій в Python-інтерпретатор і в скомпільований GCC C-рантайм з побітовим порівнянням станів.

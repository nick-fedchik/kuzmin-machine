   - Перевірено сирі файли захоплення [`raw/av11_ps_quiet_run01.lac`](raw/av11_ps_quiet_run01.lac) (базовий стан) та [`raw/av11_ps_stressed_run02.lac`](raw/av11_ps_stressed_run02.lac) (стан стресу AXI).
   - Підтверджено наявність рівно 100 висхідних фронтів на обох прогонах без пропуску жодної події.
2. **Відтворюваність розрахунків:**
   - Запущено верифікаційний скрипт [`scripts/analyze_av11.py`](scripts/analyze_av11.py).
   - Запущено регресійний тест [`scripts/test_av11_stress.py`](scripts/test_av11_stress.py).
   - Отримані результати порівняння:
     - Run 01 (Quiet): $p99 = 20.00\text{ нс}$, $t_{\max} = 20.00\text{ нс}$, $\sigma = 0.00\text{ нс}$.
     - Run 02 (100% AXI stress): $p99 = 20.00\text{ нс}$, $t_{\max} = 20.00\text{ нс}$.
     - Різниця $\Delta p99 = \mathbf{+0.00\text{ нс}}$ (конфліктів та затримок шини немає).
3. **Формальна перевірка RTL:**
   - Перевірено та виконано тестбенч [`hw/tb/s6_no_ps_dependency_tb.sv`](../../hw/tb/s6_no_ps_dependency_tb.sv) у середовищі Icarus Verilog (`test_testbenches.py`).
   - Підтверджено: вихід `txn_committed_o` не має зворотного зв'язку на PS, не генерує несанкціонованих транзакцій AXI Slave і зберігає фіксовану 1-тактову затримку навіть при штучному блокуванні шини процесором (`rready=0`, `bready=0`).
4. **Стрес-навантаження шини AXI:**
   - Підтверджено виконання 47 160 430 некешованих читань регістра AXI за 60 секунд (швидкість 790 000 оп/сек) паралельно з вимірюванням латентності.

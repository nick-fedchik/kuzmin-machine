## Обмеження

Плани, правила й реєстри не є доказами виконання. Самооцінку TRL
не підвищено перенесенням. Перенесення не делегує загальних повноважень
на зовнішні GitHub-дії; окремі статусні дії виконані за прямою командою
власника й зафіксовані в реєстрі. Публікація потребує окремого рішення.

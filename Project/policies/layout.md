# Політика розміщення та походження NG

* **Версія:** 0.2.0
* **Дата:** 2026-11-12
* **Тип WP:** Policy
* **Власник:** Микола Федчик.
* **Підстава:** прямі команди власника 2026-11-12 про три корені та копію без legacy.
* **Статус:** оформлення погодженого розміщення; не нові релізні критерії.

## 1. Мета та межі

Визначити власника змісту й місце роботи, не прирівнюючи тип WP до папки.
Застосовується до дерева Research/Engineering/Project у наявному
репозиторії. Початкове NG було локальною підготовкою; його перенесення
в Git виконується за окремою командою власника в межах
[#148](https://github.com/nick-fedchik/kuzmin-machine/issues/148).
Історія зберігається; спільний клон не використовується як робочий worktree.

## 2. Правила та відповідальність

| Правило | Умова | Дія | Відповідальний / ознака |
|---|---|---|---|
| Напрям | Новий пакет | Research — питання/гіпотези; Engineering — контракти/реалізація; Project — керування. | Автор; основний README пояснює мету. |
| Власник даних | Отримано вимірювання | Зберігати біля роботи, яка його породила; повтор — новий набір. | Виконавець; маніфест і хеші. |
| Джерело | Сторонній матеріал | Одна незмінна копія й картка Source; не дописувати метадані всередину оригіналу. | Укладач; походження й права. |
| Форма | Створено/адаптовано документ | Вибрати WP-шаблон, указати версію, межі, історію й терміни. | Автор; структурна та змістовна перевірка. |
| Зміна місця | Перенесено доказ | Рецензія й старий SHA стосуються оригіналу; перенесення не є новим результатом. | Укладач; точне посилання походження. |

## 3. Винятки

`.github/`, кореневі README/AGENTS/CLAUDE/GEMINI, `pytest.ini` та
правові входи LICENSE/NOTICE/AUTHORS — інтеграційні винятки,
не четвертий змістовний напрям.
Незмінні Source, Data та виконувані fixtures мають власний формат.
Їх не переписують для заголовків Markdown; опис форми й походження
ведеться поряд. Винятки перелічені маніфестом, не прихованим whitelist.

## 4. Перегляд і припинення дії

Зміни меж, критеріїв і повноважень приймає власник. Нові матеріали
додають у карту WP та залежностей; нова структура не скасовує попередніх
рішень заднім числом. Виявлені суперечності фіксують з об'єктом і версією.

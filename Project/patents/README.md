## Призначення та патентна стратегія

Цей розділ містить чернетки та матеріали патентних заявок на винаходи за класом комп'ютерно-реалізованих винаходів (Computer-Implemented Inventions, CII). Об'єктом правової охорони виступає не абстрактна математична чи філософська концепція, а конкретні схемотехнічні пристрої та способи апаратно-програмного керування з чітко сформульованим **цільовим вимірюваним технічним результатом** (числові межі підлягають інструментальній верифікації на фізичному стенді у Фазі 2 за `EXP-GPU-01/02`):
1. Скорочення розрахункової наскрізної латентності реакції варпа підписників на два порядки ($T_{\text{e2e}} \lt 1.0\ \mu\text{с}$ проти $100\dots 1000\ \mu\text{с}$ для класичних шин MCU);
2. Фіксована тактова тривалість детермінованого рефлекторного контуру ПЛІС ($80\text{ нс}$ @ $100\text{ МГц}$ за вільної черги) без програмного джитеру переривань ОС;
3. Усунення дивергенції варпів (Warp Divergence) для однорідних предикатно-керованих функцій на потокових мультипроцесорах GPU при резидентному розміщенні станів у регістрах і `Shared Memory` SM та когерентному вхідному буфері `Event Mailbox` (`BAR1 / Unified L2`);
4. Забезпечення переконфігурації правил у Block RAM без пересинтезу бітстріму ПЛІС (у фазово-захищеному режимі `B4-V1` або без зупинки потоку через тіньовий банк `B4-V2`).

## Маршрут патентування (Filing Roadmap)

1. **Фаза 1 (Національна пріоритетна заявка):** Подання заявки на винахід до УКРНОІВІ (Україна) для фіксації дати світового пріоритету (Day 0).
2. **Фаза 2 (Метрологічне підтвердження):** Долучення осцилограм та часових рядів експериментів [EXP-GPU-01](../../Research/studies/fpga-gpu-symbiosis/experiments/EXP-GPU-01/README.md) та [EXP-GPU-02](../../Research/studies/fpga-gpu-symbiosis/experiments/EXP-GPU-02/README.md) як доказів промислової придатності.
3. **Фаза 3 (Міжнародна заявка PCT):** Подання міжнародної заявки за процедурою Patent Cooperation Treaty (протягом 12 місяців від дати пріоритету) для резервування прав у 150+ країнах.
4. **Фаза 4 (Національні фази):** Вхід у патентні відомства США (USPTO) та Європи (EPO).

## Абревіатури та глосарій

* **CII** (Computer-Implemented Inventions) — комп'ютерно-реалізовані винаходи.
* **EPO** (European Patent Office) — Європейське патентне відомство.
* **IPC / МПК** — Міжнародна патентна класифікація.
* **PCT** (Patent Cooperation Treaty) — Договір про патентну кооперацію (міжнародне патентування).
* **USPTO** (United States Patent and Trademark Office) — Відомство з патентів і торговельних марок США.
* **УКРНОІВІ** — Український національний офіс інтелектуальної власності та інновацій.

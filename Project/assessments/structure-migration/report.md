Злиття до main не доручено. Результат подається окремим PR; зміна
локального робочого дерева спільного клону, перестворення репозиторію,
force-push, новий тег або незалежне прийняття не виконуються.

поновлюється відкладена #5. Успадковані відсутні provenance-sidecar,
namespace/import-контрприклад і lowering-прогалини не приховано.

Немає нового HIL, P&R, STA, бітстріму, TRL або підтвердження наукових тверджень.
Повний pipeline має збережені width/unused та synthesis-попередження;
strict lint проходить для вказаних у скрипті окремих компонентів.

## 2. Метод

Вхід — перевірена окрема папка NG. У власному worktree
`km-wt-copilot-148-structure` створено гілку
`chore/148-research-engineering-project` від чинного main.
Прибрано лише явно перелічені старі tracked-файли; `.git`, untracked
та ignored-файли спільного клону не чіпали. Нове дерево копіюється
за зафіксованими шляхами й SHA-256, не широким очищенням каталогу.

Чинну навігацію, Plan і Policy переведено від підготовки без Git до
окремої гілки/PR. LICENSE/NOTICE/AUTHORS включено без перепризначення
сторонніх прав. CI використовує нові шляхи; Z3 явно встановлюється
для збережених формальних перевірок. Кеші pytest і bytecode не
входять до складу міграції.

Застосовуються наявні pytest, links/WP, shell/YAML-перевірки та
RTL simulation/lint/XC7 logic synthesis. Це локальна програмна
й RTL-перевірка, не робота на фізичній платі.
Виконані команди, дата з часовим поясом, хост, версії інструментів,
SHA-256 входів і stdout/stderr записуються окремо в `raw/`.

## 5. Відтворення

З кореня міграційної гілки:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m pytest -q -p no:cacheprovider
python3 Project/tools/check_links.py
python3 Project/tools/check_wp_documents.py
bash Engineering/hw/scripts/run_open_flow.sh
```

Для перевірки pinned-посилань на `drafts` задати `KM_DRAFTS_REPO`
на локальний клон відповідного репозиторію. Без нього skipped-посилання
не означають перевірених джерел. Успіх links/WP не є змістовою атестацією.

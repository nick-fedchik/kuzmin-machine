# Внутрішні дослідження й історичні робочі матеріали

* **Версія:** 0.2.0
* **Дата:** 2026-11-12
* **Походження:** частина матеріалів — додаткова міграція `drafts@774d575:KuzminMachine`, Issue #84; нові дослідження мають окремо зазначене походження.

Це не публікації й не реєстр прийнятих результатів. Твердження, плани та самопозначення статусів можуть потребувати перевірки. Для перенесених матеріалів читабельні копії мають попередження; незмінні версії збережено окремо.

| Каталог | Матеріали |
|---|---|
| [theory/](theory/) | Досьє, порівняння машин, переклад і нові дослідницькі звіти |
| [hardware/](hardware/) | Історична апаратна архітектура, плани й описи стендових робіт |
| [software/](software/) | Проєктні мовні пропозиції, перспективні інструменти й аудиторські промпти |
| [verification/](verification/) | Історичні QA/TRL-оцінки, протоколи, незавершені програми перевірки |
| [applications/](applications/) | Внутрішні посібники та дослідження застосувань |
| [opposition/](opposition/) | Запитання до автора, проміжні проходи критики та аналіз перспектив |

Чинна редакція формального аналізу — у [docs/theory/](../theory/formal-analysis.md); раніше перенесені докази TRL — у [docs/trl-evidence/](../trl-evidence/). Старі версії не замінюють поточні вимоги чи реалізації.

Окремі нові результати: [формальна семантика #76](theory/formal-semantics-76-report.md)
і [перевірка авторського ескізу #77](theory/turing-completeness-77-report.md).
Їхні джерела, висновки й обмеження наведено в самих звітах; наявність
документа не означає незалежного рецензування.

[Межа репозиторіїв і повний архів](../PUBLICATION-BOUNDARY.md).
